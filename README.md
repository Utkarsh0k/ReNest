# ReNest

ReNest is a Full Stack Student Marketplace Web Application developed to provide a secure platform where college students can buy, sell, and browse second-hand products within their campus community.

The project aims to simplify the exchange of used items among students while promoting affordability and sustainability through a trusted marketplace.

---

## Features

### User Authentication
- User Registration
- User Login
- Secure Password Hashing using bcrypt
- JWT-based Authentication
- Protected Routes
- User Profile Management

### Marketplace
- Browse Products
- View Product Details
- Add New Product
- Edit Product
- Delete Product
- Product Categories
- Product Pricing
- Product Description

### Backend
- RESTful API Architecture
- Authentication Middleware

## Installation

### Clone the Repository

```bash
git clone https://github.com/<your-username>/ReNest.git
```

### Navigate to the Project

```bash
cd ReNest
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the project root and add the required environment variables.

Example:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Start the Development Server

```bash
npm start
```

or

```bash
npm run dev
```
